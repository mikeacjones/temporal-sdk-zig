`workflow.LocalVar(T)` is a typed value with a default, scoped to one workflow run, that libraries and interceptors read and set through the run's `*workflow.Context` from the workflow function, its coroutines, its handlers and its workflow interceptors; each run has its own values, freed with the run, and setting one from a query handler, an update validator or a side-effect function returns `error.ReadOnly`. See [Workflow-local variables](https://github.com/mikeacjones/temporal-sdk-zig/blob/main/README.md#workflow-local-variables).
