`Client.forNamespace` returns a client for another namespace of the same server that shares the existing client's connection and sdk-core runtime, so a program working in several namespaces connects once. The clients may be closed in any order, and the last to close frees the connection and runtime; `reconnect`, `updateApiKey`, and `updateHeaders` on any of them apply to all and move every worker running on them. See [Connecting](https://github.com/mikeacjones/temporal-sdk-zig#connecting).
