**Experimental**: Workflows can signal another workflow and start it if it isn't running, in one server call, with `workflow.Context.signalWithStartWorkflow` or `signalWithStartWorkflowByName`, configured by `workflow.SignalWithStartOptions`; the returned `workflow.SignalWithStartFuture` gives the run ID and whether the call started the run, and interceptors see the call on `interceptor.WorkflowOutbound.signalWithStartWorkflow`. The server must enable `history.enableSignalWithStartFromWorkflow`; see [Signal-with-start from a workflow](https://github.com/mikeacjones/temporal-sdk-zig/blob/main/README.md#signal-with-start-from-a-workflow).
