**Experimental**: `deployment.VersioningOverride` has a `.one_time` case that routes a workflow to a deployment version until one workflow task completes there; client starts and `Client.updateWorkflowExecutionOptions` send it, and `WorkflowExecutionOptions.versioning_override` reports it instead of null. Needs Temporal Server 1.32.0 or later. An exhaustive `switch` on `VersioningOverride` needs a `.one_time` prong.
**Experimental**: `workflow.ChildWorkflowOptions.versioning_override` runs a child pinned, auto-upgrading or routed once to a version, independent of its parent; a start the server refuses for its override fails the child's future with the new `error.ChildWorkflowInvalidVersioningOverride` in `workflow.ChildWorkflowError`, which an exhaustive `switch` on that error set must now handle. Needs Temporal Server 1.32.0 or later.
