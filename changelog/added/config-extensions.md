**Experimental**: `client.LoadOptions.extensions` runs each `client.ConfigExtension` after `client.loadOptions` has read the profile and the environment: it gets its own `[profile.<name>.ext.<extension>]` table as parsed values, the environment `loadOptions` reads (`client.ConfigEnv`) and the profile's name, and may change the `client.Options` being built, for example to set the API key from a secrets manager. An extension's error fails `loadOptions` with `error.InvalidConfig`, logged, and `strict` accepts any key under `ext`. See [Connecting](https://github.com/mikeacjones/temporal-sdk-zig/blob/main/README.md#connecting).
