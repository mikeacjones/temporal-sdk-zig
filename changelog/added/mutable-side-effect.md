`workflow.Context.mutableSideEffect` reads a value that is read often and changes rarely, keyed by an ID, and records it in history only when a caller-supplied comparison says it differs from the last value recorded for that ID; unchanged calls add no history events. See [Side effects, memo, and search attributes](https://github.com/mikeacjones/temporal-sdk-zig/blob/main/README.md#side-effects-memo-and-search-attributes).
