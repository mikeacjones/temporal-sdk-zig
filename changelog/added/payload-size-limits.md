`worker.Options.fail_oversized_payloads` (default true) turns off the worker's check that fails a workflow or activity task whose completion carries payloads larger than the namespace's limit, for a proxy between worker and server that changes payload sizes; see [Payload size limits](https://github.com/mikeacjones/temporal-sdk-zig/blob/main/README.md#payload-size-limits).
`client.Options.payloads_warning_size` (512 KiB) and `memo_warning_size` (2 KiB), also on `client.ConnectionOptions`, log a warning through the client's logger for each payload field or memo of a request over the size, and still send it; 0 turns a warning off. Clients now log these warnings by default, where before they logged none.
