`converter.RemoteCodec` is a payload codec that has a codec server do the work: it sends each payload list as ProtoJSON to the server's `/encode` or `/decode` over HTTP, with configurable headers, an `x-namespace` header and a timeout, and returns the list the server answers with; any failure is `error.CodecFailed` and never passes a payload through. See [Remote codec client](https://github.com/mikeacjones/temporal-sdk-zig/blob/main/README.md#remote-codec-client).
