**Experimental**: `temporal.tracing.startSpan` opens a named span with string attributes from workflow code, signal and update handlers, update validators and query handlers (never on replay, except in validators and query handlers), and the activities, child workflows, signals and Nexus operations the same coroutine starts while it is open are its children; `temporal_opentelemetry` exports it with kind internal (`tracing.Kind.internal`). The tracing interceptor also opens `SignalExternalWorkflow` and `SignalChildWorkflow` spans for signals a workflow sends. See [Tracing](https://github.com/mikeacjones/temporal-sdk-zig/blob/main/README.md#tracing).
