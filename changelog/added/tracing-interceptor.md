`temporal.tracing.Interceptor` opens spans around client calls, workflow runs and handlers, activities, child workflows and Nexus operations, carries their context in the `_tracer-data` header so one trace spans client, workflow and activity, and starts no span on replay; a backend implements `temporal.tracing.Tracer`. The module `temporal_opentelemetry`, added with `-Dopentelemetry`, implements it on the OpenTelemetry Zig SDK and exports spans over OTLP HTTP/protobuf. See [Tracing](https://github.com/mikeacjones/temporal-sdk-zig/blob/main/README.md#tracing).
