`testing.MetricsRecorder` is a thread-safe `metrics.Handler` for tests: give its `handler()` to `ActivityEnvironment.metrics` or to `WorkflowEnvironment.startWithOptions(.{ .metrics = .{ .exporter = .{ .custom = ... } } })`, and `recordsOf(arena, name)` returns every value recorded to a metric, with its definition and flattened attributes (`Record.get(key)` reads one), while `hasMetric(name)` says whether the metric was created.
