`Client.queryWorkflow`, `queryWorkflowWithOptions`, `queryWorkflowByName` and `queryWorkflowByNameWithOptions` now return `error.DeadlineExceeded`, a new member of `QueryError`, when the call's deadline (`RpcOptions.timeout` or `Options.rpc_timeout`) passes, for example because no worker is polling; before, they returned `error.RpcFailed` and logged it at err. Handle `error.DeadlineExceeded` where you caught `error.RpcFailed` for a query timeout, and add it to any exhaustive `switch` on `QueryError`.
