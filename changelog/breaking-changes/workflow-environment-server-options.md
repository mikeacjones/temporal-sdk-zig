`testing.WorkflowEnvironment.Options` takes the servers' own options as `dev_server` (a `testing.DevServer.Options`) and `test_server` (a `testing.TestServer.Options`), in place of `dev_server_extra_args` and `dev_server_cli_version`: write `.dev_server = .{ .extra_args = &args }` for `.dev_server_extra_args = &args`, and `.dev_server = .{ .cli_version = version }` for `.dev_server_cli_version = version`. The environment still registers `testing.custom_search_attributes`, along with any `dev_server.search_attributes`.
`testing.WorkflowEnvironment.startTimeSkippingWithOptions` now returns `error.InvalidOptions` for a `dev_server` with any field other than its default, including a CLI version, which before was only a warning; `startWithOptions` does the same for a non-default `test_server`. Remove the other server's options from the call.
