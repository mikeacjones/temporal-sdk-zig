Header fields now skip the payload codecs (`client.Options.codecs`) unless the `propagation.ContextPropagator` that writes them sets `encode_fields`, and fields interceptors write are sent as written; before, every header field was encoded. To keep a propagator's fields encoded, set `.encode_fields = true` on it, or use `propagation.HeaderPropagator(k).encoded_propagator` instead of `.propagator`. Received header fields are still decoded, so a codec must pass through payloads it didn't encode.
