Payload codecs on a caller workflow's worker now code a Nexus operation's schedule command (its input and summary) and its resolutions (its result and failure) with the operation's context, `converter.Context.nexus` set and without the calling workflow's ID and type, instead of the run's context; the payload converter's hooks for the input and result, and the failure converter for its failure, get the same context instead of the namespace and propagated values alone. A workflow's signal-with-start keeps the run's context.
