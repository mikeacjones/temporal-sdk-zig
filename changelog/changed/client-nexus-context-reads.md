**Experimental**: `ActivityHandle.describe` decodes the heartbeat details and the last failure of an activity a Nexus handler started with the propagated Nexus context the server returns (`ActivityDescription.heartbeat_details.context.nexus`), for the payload codecs, the payload converter's context hooks and the failure converter, and now passes `raw.last_failure` through `client.Options.failure_converter` with or without that context.
**Experimental**: `NexusOperationHandle.get` decodes a standalone Nexus operation's result and failure with `converter.Context.nexus` set to the propagated context the server sends with them or, without one, to the new `NexusOperationHandle.nexus_context`, which `Client.executeNexusOperation` and `executeNexusOperationByName` set to the start's endpoint, service and operation; a handle from `Client.getNexusOperationHandle` without a propagated context still decodes with the namespace alone.
