`testing.WorkflowReplayer` now returns `error.InvalidHistory`, with a message naming the problem, for a history the core can't replay: one whose started event has no task queue, whose workflow task started event is followed by something other than the task's completion, failure or timeout, whose workflow tasks share a started event ID, whose first event ID is above 1, or which ends before its last workflow task started event. Such a history used to hang the replay; the histories after it in the same `replayHistories` call now replay normally.
