A project that depends on the SDK no longer hangs in time-skipping tests that send an update when a broken test server release comes out: `testing.TestServer` and `WorkflowEnvironment.startTimeSkipping` now download the newest release the SDK's own tests pass with, v1.41.1 (v1.41.0 never delivers an update), in place of sdk-core's newest; pass `.@"test-server-version" = "default"` in `b.dependency`'s arguments to get sdk-core's choice back. The earlier notes spelled the argument `.test_server_version`, which Zig ignores with only a logged error. See [Testing](https://github.com/mikeacjones/temporal-sdk-zig#testing).
