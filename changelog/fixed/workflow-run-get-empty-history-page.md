`WorkflowRun.get`, `WorkflowRun.getWithOptions` and `WorkflowEnvironment.getResult` now keep waiting while the run is open when the server's long poll ends with an empty history page and no page token, as the time-skipping test server's does after 20 s, instead of returning `error.InvalidResponse`. A run that has closed but whose history keeps coming back without a close event returns `error.InvalidResponse` after 3 such pages, logged as a warning, and a run that no longer exists returns `error.NotFound`.
