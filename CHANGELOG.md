# Changelog

All notable changes to this project are documented in this file, one section per release, newest first. The project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html) as described in [docs/releasing.md](docs/releasing.md), and [docs/upgrading.md](docs/upgrading.md) shows how to move code across releases with breaking changes.

This file holds completed releases only. Changes that haven't been released yet are fragments under [changelog/](changelog/README.md); `scripts/changelog-assemble.sh` turns them into a release's section when the release is prepared.
